LTRp_XlsxToJSON 離線安裝包

安裝步驟：
1. 執行 python/python-3.12.2-amd64.exe 安裝 Python
   - 安裝時請勾選 "Add Python to PATH"
   - 建議使用預設安裝路徑

2. 執行 install.bat 安裝必要套件與程式
   - 會自動安裝所需的 pip 套件
   - 複製程式檔案到使用者目錄

3. 安裝完成後，可以：
   - 使用 GUI：執行安裝目錄中的 run.bat
   - 使用命令列：參考 docs/使用前請先閱讀此份文件.txt

系統需求：
- Windows 10 或更新版本
- 4GB 以上記憶體
- 500MB 可用硬碟空間
